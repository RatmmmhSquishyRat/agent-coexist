# agent-coexist

When the task is genuine shared-file coordination, or existing coexist notes are relevant, use the CLI. Do not only discuss it. Run `agent-coexist guide` first; exact syntax: `agent-coexist guide --help`. The guide decides adoption.

Activation is not a write. Read-only inquiry may run guide without creating files. Unrelated ordinary-word mentions must not create files.

Prefer an available `agent-coexist` binary, PATH or explicit path. `--as` is a label, not authority. `locked` is cooperation, not access control. `warn` is exit 0. Not a network, scheduler, authenticator, or message queue.
